# Cópia de segurança: Piratininga v282, antes dos novos desenhos de 1554 (24/11/2026)

Estes 3 arquivos são exatamente como estavam antes da atualização gráfica da etapa 1554:
`piratininga.html`, `arte/arte_1554.js` e `arte/pac_e1.js`.

Para voltar ao jogo antigo, copie `piratininga.html` para `jogos/` e os dois arquivos de `arte/` para `jogos/arte/`
(e depois rode `python3 jogos/ferramentas/abertura_rapida.py`).
Para só desligar os desenhos novos sem trocar arquivos: `window.NOVOS54_DESLIGADOS=true` antes de o jogo carregar.
